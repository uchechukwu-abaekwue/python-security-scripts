## Project 1: Basic Password Strength Checker (`password_checker.py`)
This script evaluates the architectural complexity of user-inputted passwords based on standard security protocols.

### Key Evaluation Metrics:
* **Length Verification**: Validates that the input is at least 8 characters long.
* **Character Diversity**: Utilizes Regular Expressions (re) to verify the integration of numerical digits.
* **Special Character Mapping**: Flags missing special characters (e.g., `@`, `#`, `$`) to prevent basic brute-force exploits.
